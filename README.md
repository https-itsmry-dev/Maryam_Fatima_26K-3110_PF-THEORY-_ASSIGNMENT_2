## Repository Inlcudes the following tasks:

* **Task 1 (Cinema Hall):** A 2D-array program that displays a cinema's seating chart and allocates consecutive seats to a group by searching rows outward from the middle.
  
*   **Task 2 (Amicable Pairs):** A program that finds and displays all amicable number pairs up to a user-defined limit by using a divisor-sum function.
  
*   **Task 3 (Greenhouse):** A 2D-array program that analyzes hourly temperature readings per sensor, reporting totals, averages, extremes, and the longest hot streak.
  
*   **Task 4 (Bakery Festival):** A modular program that calculates daily and total festival sales, identifies the best sales day, and prints a star-based bar chart.
  
*   **Task 5 (Library Management):** A menu-driven program using arrays and functions to manage member registration, book borrowing, returns, and late-fee calculations with waivers.
